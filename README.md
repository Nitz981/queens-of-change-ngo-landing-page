Empower Her Foundation

Empower Her Foundation is a women-focused NGO dedicated to empowering women and girls through education, skill development, healthcare awareness, leadership programs, and community support.

🌟 Features

- Responsive Landing Page Design
- Hero Section with Call-to-Action
- About Us Section
- Women Empowerment Programs
- Volunteer & Donation Section
- Contact Information
- Social Media Links
- Modern and User-Friendly UI

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
